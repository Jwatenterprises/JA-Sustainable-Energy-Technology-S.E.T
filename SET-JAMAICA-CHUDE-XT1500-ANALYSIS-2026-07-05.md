1. **Price Confirmation:** king jin's written quote was $420 CIF Kingston (1 unit). The Alibaba listing shows $900-$1,000. king jin says the listing was a pricing error by a previous employee. Need written confirmation of the corrected price per unit at 1, 5, and 50 units CIF Kingston.

2. **MPPT Discrepancy:** Spec sheet says 400W MPPT via XT60, but distributor page says 240W. Are there different versions? Which version is quoted for Jamaica?

3. **Voltage/Frequency Confirmation:** Distributor page shows 110V. Jamaica uses 110V/50Hz. Need written confirmation this model supports 50Hz (the LCD display diagram in the spec sheet shows both 50Hz and 60Hz indicators, which is promising).

4. **Certification Documents:** Distributor page lists UL, CE, FCC, PSE, BSMI certifications. king jin must provide the actual certificate PDFs matching the XT1500 model — especially UN38.3 and MSDS for international shipping.

5. **Warranty/Replacement:** Who handles warranty — EAST directly, Chude, or the buyer? What is the warranty period? Replacement process and freight responsibility for defective units.

6. **Trade Assurance:** Confirm Alibaba Trade Assurance covers the full order value, shipping, quality, and replacement claims.
